# Security

## Reporting a vulnerability

Please do not open a public issue for a vulnerability.

Report it privately on GitHub: on this repository, open **Security**, then **Report a
vulnerability**. Say what is affected, how to reproduce it, and what someone could do with it.

You will get an answer when the report has been read, and again when there is a fix or a
decision. Please give us time to release a fix before you publish anything.

## Supported versions

There is no release yet. Once there is, fixes go to the newest version.
