## The claim

- A stop, a steer or a config change that arrives mid-reply is just the next message.

## In a loop

- They arrive while the loop is suspended in an `await`, so they need queues, flags and locks.

## As a reducer

- Each is a message to `step`, taken in turn.

## The proof

- A run example, pi's input tests and the conformance ordering scenarios.
