**The claim:** new code can take over a session that is waiting, between two
of its steps, with no session finished early or lost. An upgrade is a message
like any other.

## In a loop

A loop that reminds someone later:

```ts
async function remind(text: string, inSeconds: number) {
  await sleep(inSeconds * 1000);
  notify(text);
}
```

A reminder set for next week is a call paused in `sleep` for a week, running
this version of the code. To deploy a fix in that time, there are three
choices, and none is good:

- **Wait.** Keep the old process running until every pending reminder has
  fired, maybe for a week, beside the new one.
- **Restart.** Stop the old process, and lose every reminder in it.
- **Rewrite.** Keep reminders in a database, and run a scheduler that reads
  them, so a new version can pick them up. That is turning the loop into a
  state machine by hand.

A model loop has the same problem. A conversation waiting on a model or a
person is a paused function, and its progress is in that function's frames.

## As a reducer

A waiting session is data: a snapshot, a log and the effects it declares. To
upgrade it, the runner waits for the step in progress to finish, gives the old
snapshot to the new version's `migrate`, saves what it returns, and delivers
`migrated` as the new code's first message. Effects the old code started keep
running, and their results go to the new code.

Version 1 keeps each reminder's `text` and `at`:

```ts title="src/v1.ts"
import type { Agent, NoConfig } from '@acentric/types';

type Reminder = { key: string; text: string; at: number };
type Snapshot = { reminders: Reminder[] };

export type ReminderKinds = { '@timer': { args: { at: number }; result: null } };

const v1: Agent<Snapshot, NoConfig, ReminderKinds> = {
  name: 'reminders',
  version: '1',
  kinds: ['@timer'],

  init: () => ({ snapshot: { reminders: [] } }),

  step: ({ snapshot }, message, now) => {
    if (message.type === 'input' && message.kind === 'remind') {
      const text = String(message.payload['text']);
      const at = now + Number(message.payload['inSeconds']) * 1000;
      const reminder = { key: `remind:${message.id}`, text, at };
      return { snapshot: { reminders: [...snapshot.reminders, reminder] } };
    }
    if (message.type === 'effect') {
      const due = snapshot.reminders.find((r) => r.key === message.key);
      return {
        snapshot: { reminders: snapshot.reminders.filter((r) => r !== due) },
        append: due === undefined ? [] : [{ kind: 'reminder', body: due.text }],
      };
    }
    return { snapshot };
  },

  effects: ({ snapshot }) =>
    snapshot.reminders.map((r) => ({ key: r.key, kind: '@timer', args: { at: r.at } })),
};

export default v1;
```

Version 2 renames them `message` and `dueAt`, and logs how late each reminder
fired. Its `migrate` moves version 1's reminders into the new shape:

```ts title="src/v2.ts"
import type { Agent, Json, JsonObject, NoConfig } from '@acentric/types';

import type { ReminderKinds } from './v1.js';

type Reminder = { key: string; message: string; dueAt: number };
type Snapshot = { reminders: Reminder[] };

/** A version 1 reminder, `{ key, text, at }`, in version 2's shape. */
function fromV1(old: Json): Reminder {
  const r: JsonObject =
    typeof old === 'object' && old !== null && !Array.isArray(old) ? old : {};
  return { key: String(r['key']), message: String(r['text']), dueAt: Number(r['at']) };
}

const v2: Agent<Snapshot, NoConfig, ReminderKinds> = {
  name: 'reminders',
  version: '2',
  kinds: ['@timer'],

  init: () => ({ snapshot: { reminders: [] } }),

  migrate: (snapshot) => {
    const old = snapshot['reminders'];
    return { snapshot: { reminders: Array.isArray(old) ? old.map(fromV1) : [] } };
  },

  step: ({ snapshot }, message, now) => {
    if (message.type === 'migrated') {
      return { snapshot, append: [{ kind: 'upgraded', body: { from: message.from } }] };
    }
    if (message.type === 'input' && message.kind === 'remind') {
      const text = String(message.payload['text']);
      const dueAt = now + Number(message.payload['inSeconds']) * 1000;
      const reminder = { key: `remind:${message.id}`, message: text, dueAt };
      return { snapshot: { reminders: [...snapshot.reminders, reminder] } };
    }
    if (message.type === 'effect') {
      const due = snapshot.reminders.find((r) => r.key === message.key);
      return {
        snapshot: { reminders: snapshot.reminders.filter((r) => r !== due) },
        append:
          due === undefined
            ? []
            : [
                {
                  kind: 'reminder',
                  body: { message: due.message, lateBy: now - due.dueAt },
                },
              ],
      };
    }
    return { snapshot };
  },

  effects: ({ snapshot }) =>
    snapshot.reminders.map((r) => ({
      key: r.key,
      kind: '@timer',
      args: { at: r.dueAt },
    })),
};

export default v2;
```

A session sets a reminder on version 1 and is upgraded to version 2 while its
timer is waiting. The timer keeps running, because version 2 declares the same
key, and when it fires, version 2 handles it:

```ts title="upgrade.ts" run
import assert from 'node:assert/strict';
import { setTimeout as sleep } from 'node:timers/promises';

import { createMemoryRunner } from '@acentric/runner-memory';

import v1 from './src/v1.js';
import v2 from './src/v2.js';

const runner = createMemoryRunner();
const one = runner.load(v1);
const two = runner.load(v2);
const { id } = runner.create(one, {});
if (id === undefined) throw new Error('the session was not created');

await runner.input(id, 'remind', { text: 'stretch', inSeconds: 0.1 }, 'r1');
assert.deepEqual(await runner.upgrade(id, two), { accepted: true });

// The reminder is in version 2's shape, and its timer is still running.
assert.match(JSON.stringify(runner.snapshot(id)), /"message":"stretch","dueAt":\d+/);
assert.deepEqual(
  runner.running(id).map((effect) => effect.key),
  ['remind:r1'],
);

// When it fires, version 2's step handles it.
await sleep(300);
const log = runner.log(id);
assert.deepEqual(log[0]?.body, { from: '1' });
assert.equal(log[1]?.kind, 'reminder');
assert.match(JSON.stringify(log[1]?.body), /^\{"message":"stretch","lateBy":\d+\}$/);
runner.close();
```

## The proof

- **The example above runs in our docs check,** on the memory runner.
- **The conformance scenarios check it on every runner that offers upgrades:**
  an upgrade runs `migrate` and delivers `migrated` first, and a `migrate` that
  rejects leaves the session on its old version.
- **`acentric dev` depends on it.** Every save builds a new version and upgrades
  the project's sessions to it, keeping their state. A session the local runner
  stopped because a step failed is fixed the same way: save the fix, and the
  upgrade clears the fault and steps the failed message again on the new code.
